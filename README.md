# Tunnely VPN

Windows-клиент (Windows 10/11, x64) для подключения к VPN по ключам и подпискам. Сетевое ядро — [Mihomo](https://github.com/MetaCubeX/mihomo).

## Установка (для клиентов)

1. Запустите `Tunnely-VPN-Setup-1.0.0.exe`.
   Windows может показать окно SmartScreen «Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае»
   (окно исчезнет, когда установщик будет подписан сертификатом, см. ниже).
2. Выберите папку и нажмите «Установить». Права администратора не нужны.
3. Скопируйте ключ или ссылку на подписку, которые вы получили, откройте Tunnely и нажмите **«Вставить ключ из буфера»**.
4. Нажмите на тоннель — когда в конце загорится свет, VPN включён.

Удаление — через «Параметры → Приложения». При удалении приложение выключает системный прокси и убирает автозапуск.

## Возможности

- Подключение одной кнопкой, статус, таймер, скорость, трафик за сеанс, задержка.
- Ключи: ссылки на подписку (https://…), vless:// (Reality, TLS, XTLS-Vision, постквантовое шифрование), vmess://, trojan://, ss://, hysteria2://, tuic://, anytls:// и др., файлы конфигурации Clash/Mihomo.
  Добавление из буфера обмена, вручную и из файла. Несколько профилей.
- Подписки: автообновление (интервал задаёт сервер, по умолчанию 12 ч), название, остаток трафика и срок действия
  (стандартные заголовки `profile-title`, `subscription-userinfo`, `support-url`).
- Серверы: флаги стран, задержка, выбор, «самый быстрый», группа автовыбора из подписки.
- **Режимы:** «Умный» (всё через VPN, кроме российских сайтов и ваших исключений — сайтов и программ) и «Весь трафик через VPN».
- Способ подключения: системный прокси (без прав администратора) или TUN (весь трафик системы; приложение перезапускается с правами администратора по запросу).
- Автопереподключение: проверка сервера каждые 20 с, переключение на рабочий сервер, перезапуск ядра при сбое.
- Трей с меню (подключение, сервер, режим), сворачивание в трей, автозапуск с Windows, запуск свёрнутым.
- Журнал ядра и приложения (ключи, UUID, пароли и адреса подписок вырезаются), активные соединения, правила.
- Автообновление приложения с проверкой SHA-512.

## Безопасность

- Адреса подписок хранятся зашифрованными средствами Windows (DPAPI) в `%APPDATA%\Tunnely VPN`.
- Управляющий интерфейс ядра слушает только 127.0.0.1 и защищён случайным паролем, который меняется при каждом запуске.
- Прежние настройки прокси Windows сохраняются перед подключением и восстанавливаются при отключении, выходе, завершении работы Windows,
  а также при следующем запуске, если приложение было аварийно закрыто.
- Ключи и конфигурации никуда, кроме вашего сервера подписки, не отправляются.

## Сборка (для разработчика)

Нужны Node.js 22+ и Windows. Все команды — в папке `tunnely`:

```bash
npm install
```

```bash
npm run dist
```

`npm run dist` собирает ядро Mihomo из официальных исходников с правками совместимости (см. ниже; Go скачивается автоматически
в `.tools` с проверкой SHA-256), собирает помощник, генерирует иконки, проверяет типы
и создаёт установщик в `release/`.

Проверки:

```bash
npm test
```

Сквозной тест с настоящим подключением (ключ передаётся только через переменную окружения):

```bash
TUNNELY_TEST_KEY="ваш ключ" node tests/e2e.mjs release/win-unpacked/Tunnely.exe
```

## Собственная сборка ядра

Новые серверы Xray (26.7+) отклоняют стандартный Mihomo с ошибкой «REALITY authentication failed». Поэтому `scripts/build-core.mjs`
собирает Mihomo с тремя правками в `component/tls/reality.go` (текст — `patches/mihomo-reality-version.diff`):
версия клиента REALITY 26.10.21, всегда X25519MLKEM768, отпечаток Chrome вместо Firefox.
Другая версия ядра: `MIHOMO_TAG=v1.19.34 npm run build-core`. Если правка не применится (Mihomo изменил код), сборка остановится с ошибкой.

## Выпуск обновлений

1. Один раз: в `electron-builder.yml` в разделе `publish` замените `url` на адрес папки на вашем сервере (например `https://ваш-сайт/tunnely/`).
2. Увеличьте `version` в `package.json` (например 1.0.1).
3. Выполните `npm run dist`.
4. Загрузите в эту папку на сервере три файла из `release/`: `latest.yml`, `Tunnely-VPN-Setup-<версия>.exe`, `Tunnely-VPN-Setup-<версия>.exe.blockmap`.

Установленные приложения проверяют обновления при запуске и каждые 6 часов, скачивают их, сверяют SHA-512 и устанавливают при перезапуске.
Важно: версии, собранные до шага 1, не знают адрес сервера и не обновятся автоматически — их нужно один раз переустановить.

## Известные ограничения

- Установщик не подписан сертификатом разработчика — Windows SmartScreen предупреждает при первом запуске. Для распространения
  рекомендуется купить сертификат подписи кода (OV/EV) и указать его в `electron-builder.yml` (`win.signtoolOptions`).
- Режим TUN требует прав администратора (ограничение Windows для создания виртуального адаптера).
- Исключения программ в режиме «системный прокси» действуют только для программ, которые используют системный прокси; для остальных нужен TUN.
- Список «российских сервисов» — встроенный набор доменов (.ru, .рф, .su и популярные сервисы); полной базы IP-адресов РФ нет.
